# Harness hooks index

One bullet per installed hook: event, what it denies or records, escape hatch. The hook header is the reference for env names, sentinel paths, caps, deny wording and exit codes. Switches: [opt-in-surfaces.md](opt-in-surfaces.md). Limits: [known-limits.md](known-limits.md). Skills link this index instead of restating hook internals.

## Session-scoped activation

Every hook below acts only in sessions where the protocol is active, except `client-term-guard`, `deck-inspection-gate` and the four ledger gates (`onboarding-ledger-gate`, `onboarding-ledger-write-gate`, `perf-onboarding-ledger-gate`, `perf-onboarding-ledger-write-gate`), which are scoped by their own file or opt-in; elsewhere hooks pass through. Hooks register system-wide with `npm install -g` and per project with a plain `npm install`. Detection lives in [`hooks/lib/achilles-activation.sh`](../../../hooks/lib/achilles-activation.sh). Signals, in order: `ACHILLES_PROTOCOL=1`; the per-session marker the watcher writes; a protocol-shaped tool call; a transcript signature (Achilles Skill call, typed `/<skill>`, Read of an Achilles `SKILL.md`). A payload without `session_id` counts as active.

**Lifecycle.** Activation is one-way. Only two events end it: a sanctioned ledger write landing `complete` or `aborted` on `onboarding-status.json` / `perf-onboarding-status.json` (the watcher retires the marker), or session end. `ACHILLES_PROTOCOL=0` suppresses activation but never deactivates a session whose marker exists. `~/.claude/achilles/` is protected even in inactive sessions (`protected-artifact-bash-guard` for Bash, `harness-self-protection-guard` for Write|Edit). Every deny appends `achilles_scope_notice()`: for an unrelated task, end the session and start a fresh one. After completion the enforcement gates go quiet; `run-summary-writer`, `perf-summary-writer` and `playwright-cli-cleanup-on-stop` still run via the `.completed` marker. A fresh explicit Achilles invocation re-opens the protocol.

### Skill / Agent / UserPromptSubmit

- **[achilles-protocol-activation-watcher](../../../hooks/achilles-protocol-activation-watcher.sh)** — `PreToolUse:Skill|Agent`, `UserPromptSubmit`, `PostToolUse:Write|Edit`. Observe-only. Writes the session marker `~/.claude/achilles/sessions/<session_id>.active` on an Achilles Skill call, a distinctly Achilles role-prefixed dispatch, or a typed `/<skill>`; retires it on a terminal ledger write; prunes markers older than 7 days. The gates re-check the signatures themselves, so it is a cache. [escape hatch: none; `ACHILLES_PROTOCOL=0` suppresses marking]

## PreToolUse

### All tools (kernel mandate)

- **[achilles-kernel-activation-gate](../../../hooks/achilles-kernel-activation-gate.sh)** — `PreToolUse:.*`. Registered wrapper: runs the vendored kernel only while the protocol is active and relays its verdict and exit status unchanged. Behind activation so a project that only installed the package is not governed until an Achilles skill runs. Kernel script missing: deny if the project has `.claude/kernel-mandate.json`, else allow. [escape hatch: `KERNEL_MANDATE=0` in the operator shell]
- **kernel-mandate-role-gate** (`hooks/kernel-mandate-role-gate.sh`, not registered; the wrapper execs it). Per-role tool, Bash, read and write grants from `.claude/kernel-mandate.json`, staged from `hooks/data/achilles-qa.kernel-mandate.json` by postinstall and never overwritten. Vendored from [civitas-cerebrum/kernel-mandate](https://github.com/civitas-cerebrum/kernel-mandate); edit upstream only; decisions log to `.claude/kernel-mandate.state/decision-log.jsonl` ([hook-authoring](../../contributing-to-achilles-protocol/references/hook-authoring.md) §"Vendored kernel"). Roles: [achilles-qa.kernel-mandate.md](../../../hooks/data/achilles-qa.kernel-mandate.md); dispatch spelling: [roles-and-dispatch.md](roles-and-dispatch.md). [escape hatch: operator-only, `KERNEL_MANDATE` row in opt-in-surfaces.md]

### Edit / Write

- **[test-id-compliance-gate](../../../hooks/test-id-compliance-gate.sh)** — `PreToolUse:Edit|Write` on `*.spec.*`, `*.test.*`, `*.setup.*`. Denies a newly added `test(...)` / `test.only|skip|fail|fixme(...)` whose title lacks a leading ID (default `TCXX-NNNNNN`; `CIVITAS_TEST_ID_PATTERN` swaps the shape), or an ID that repeats in the file. Existing titles are not rescanned. [escape hatch: `CIVITAS_DISABLE_TEST_ID_GATE=1`]
- **[achilles-import-boundary-gate](../../../hooks/achilles-import-boundary-gate.sh)** — `PreToolUse:Edit|Write` on root `playwright*.config.*`, root `package.json`, and everything under `tests/`. Static screen: nothing the orchestrator's `npx playwright test` loads may import or point outside `tests/` (allowlisted packages and Node builtins only; dynamic or unparseable constructs deny). A floor against careless reach into `src/`, not a sandbox; unmodelled channels in KL-03. Rule list: `hooks/lib/import-boundary-scan.js`. [escape hatch: none]
- **[achilles-multiedit-gate](../../../hooks/achilles-multiedit-gate.sh)** — `PreToolUse:MultiEdit`. Denies MultiEdit while the protocol is active; the Write/Edit gates do not inspect it. [escape hatch: none]
- **[selector-development-activation-gate](../../../hooks/selector-development-activation-gate.sh)** — `PreToolUse:Edit|Write` on frontend source. Denies selector-development edits when the workspace lacks a recognised frontend framework dependency or a `tests/e2e/*.spec.ts` directory. [escape hatch: none]
- **[selector-development-inertness-guard](../../../hooks/selector-development-inertness-guard.sh)** — `PreToolUse:Edit|Write` on frontend source. Denies a selector-development edit unless it is a single additive attribute matching the project's selector convention. [escape hatch: env override, see hook header]
- **[selector-development-pipeline-stepper](../../../hooks/selector-development-pipeline-stepper.sh)** — `PreToolUse:Bash|Edit|Write` (gate) and `PostToolUse:Bash|Edit|Write` (record). Enforces the 8-step order (before-snapshot, patch, typecheck, unit, e2e, after-snapshot, visual-diff, commit); records each step's outcome on the scope receipt. [escape hatch: none]
- **[client-term-guard](../../../hooks/client-term-guard.sh)** — `PreToolUse:Write|Edit` into this package's repo only. Denies content or paths matching a term in the operator-local `<repo-root>/.achilles/client-terms.local.txt` (gitignored; the terms must never ship). No denylist: no-op. Runs without the activation gate. Rule: `contributing-to-achilles-protocol` §"Universality — no client references". [escape hatch: edit or remove the denylist]
- **[perf-onboarding-ledger-write-gate](../../../hooks/perf-onboarding-ledger-write-gate.sh)** — `PreToolUse:Write|Edit` on `tests/perf/docs/perf-onboarding-status.json`. Validates the schema and state-machine transitions, approver identity, mode authorisation, `reviewerCycles`, and the per-phase deliverables. [escape hatch: none]
- **[onboarding-ledger-write-gate](../../../hooks/onboarding-ledger-write-gate.sh)** — `PreToolUse:Write|Edit` on `tests/e2e/docs/onboarding-status.json`. Validates the schema (`hooks/lib/validator.bundle.mjs`; without `node` or the bundle only that check is skipped), then denies `runMode` changes without a `modeAuthorizer` quote, unauthorised phase skips, `approved` outside a registered reviewer context or with a null `handoverEnvelope`, `reviewerCycles` jumps, and `completed` without deliverables. Transitions: [ledger-vocabulary.md](ledger-vocabulary.md). [escape hatch: none]
- **[harness-self-protection-guard](../../../hooks/harness-self-protection-guard.sh)** — `PreToolUse:Write|Edit`. Denies writes under `*/.claude/hooks/*` and to `settings.json` / `settings.local.json`, after path normalisation. Hook changes go through `hooks/<file>.sh` and `npm run sync-hooks`. Project `.claude/skills/*` stays writable. [escape hatch: none]
- **[hook-authored-state-guard](../../../hooks/hook-authored-state-guard.sh)** — `PreToolUse:Write|Edit`. Denies direct writes to `.workflow-approvers.json` and `.ledger-integrity.json`. Denies a write to `.phase4-cycle-state.json` or `coverage-expansion-state.json` that shrinks a dispatched/returned roster or starts with `returned-*` non-empty. [escape hatch: operator-only]
- **[failure-diagnosis-evidence-floor-gate](../../../hooks/failure-diagnosis-evidence-floor-gate.sh)** — `PreToolUse:Write|Edit` on specs and `page-repository*.json`. In a failure-diagnosis session, denies the write when the transcript shows no access to failure evidence (trace, `error-context.md`, screenshot, video, reporter JSON, or a `show-trace` / `show-report` / `gh run download` call). Proves access, not understanding. [escape hatch: `FD_EVIDENCE_FLOOR_GATE=off`]
- **[journey-map-sentinel-gate](../../../hooks/journey-map-sentinel-gate.sh)** — `PreToolUse:Write|Edit`. Denies a `journey-map.md` write whose line 1 is not `<!-- journey-mapping:generated -->`, a `journey-map-coverage.md` write without a sentinel-bearing map, and a first map write with no cycle-1 section dispatches in `.phase4-cycle-state.json`. [escape hatch: none]
- **[ledger-integrity-chain](../../../hooks/ledger-integrity-chain.sh)** — `PreToolUse:Write|Edit` (verify) and `PostToolUse:Write|Edit` (record). Hash chain in `tests/e2e/docs/.ledger-integrity.json` over the onboarding ledger and the two orchestrator-written progress files. Out-of-band edits drift from the chain and the next gated write denies. Detects what `protected-artifact-bash-guard` fails to prevent. [escape hatch: operator-only, restore the file or delete the sidecar in a human terminal]

### Agent

- **[subagent-schema-preread-gate](../../../hooks/subagent-schema-preread-gate.sh)** — `PreToolUse:Agent`. Denies a schema-validated role dispatch whose brief omits the schema citation. [escape hatch: none]
- **[standard-mode-first-pass-guard](../../../hooks/standard-mode-first-pass-guard.sh)** — `PreToolUse:Agent`. Under `runMode: standard`, denies pass-1 grouped dispatches, `phase4-prioritise-author:` before two distinct cycle-1 sections are dispatched, and single-subagent walkthroughs of journey-mapping cycle 1. Under `depth` it applies to every pass and cycle. Mode is read from `tests/e2e/docs/onboarding-status.json`. [escape hatch: none]
- **[workflow-approver-registry](../../../hooks/workflow-approver-registry.sh)** — `PreToolUse:Agent`. Records each `workflow-reviewer-*` / `phase-validator-*` dispatch by `tool_use_id` in `tests/e2e/docs/.workflow-approvers.json`, so the ledger gate can check who approves. Never denies. [escape hatch: n/a]
- **[workflow-reviewer-brief-gate](../../../hooks/workflow-reviewer-brief-gate.sh)** — `PreToolUse:Agent`. Denies a `workflow-reviewer-*` brief that lacks the `onboarding-status.json` reference, a verification verb (`Read` / `verify` / `inspect`), or 400 characters of substance. [escape hatch: `WORKFLOW_REVIEWER_BRIEF_GATE=off`]
- **[onboarding-ledger-gate](../../../hooks/onboarding-ledger-gate.sh)** — `PreToolUse:Agent`. Reads the ledger and denies non-reviewer dispatches while the prior phase's `reviewerVerdict` is `pending`, and out-of-order phase, pass or cycle dispatches. Reviewer dispatches pass. A missing or malformed ledger allows, so a new run can start. [escape hatch: none]
- **[perf-onboarding-ledger-gate](../../../hooks/perf-onboarding-ledger-gate.sh)** — `PreToolUse:Agent`. Same gate for `tests/perf/docs/perf-onboarding-status.json`: pending verdicts, out-of-order phases, and Phase-5 passes out of order (load, stress, spike, soak). `perf-reviewer-*` passes, subject to the 3-cycle cap. [escape hatch: none]
- **[composition-judge-gate](../../../hooks/composition-judge-gate.sh)** — `PreToolUse:Agent` and `PostToolUse:Agent` (record), `Stop` (block). Records `composition-judge-*` dispatches and verdicts in `~/.claude/achilles/composition-judge/`. At Stop, blocks while the last verdict is `improvements-needed` and fewer than 3 rejects have occurred; once per Stop via `stop_hook_active`. Dispatching a judge at all is not detectable (markdown-only, anti-rationalizations §"markdown-only deferral — judge-loop arming"). [escape hatch: none; self-clears at the cap, on `greenlight`, or on a repeat Stop]
- **[journey-mapping-skill-preread-gate](../../../hooks/journey-mapping-skill-preread-gate.sh)** — `PreToolUse:Agent|Write|Edit`. Denies `phase4-cycle-*` / `phase4-prioritise-author:` dispatches, writes to `journey-map.md` / `journey-map-coverage.md`, and spill writes under `.subagent-returns/phase4-*` unless the transcript shows `Skill('journey-mapping')` or a Read of its `SKILL.md`. [escape hatch: `JOURNEY_MAPPING_PREREAD_GATE=off`]

### Bash

- **[perf-load-safety-gate](../../../hooks/perf-load-safety-gate.sh)** — `PreToolUse:Bash` on `k6 run`. Fixed ceilings, not read from config: VUs at most 1000, duration at most 3600 s, origin in the `perf-onboarding.config.json` allowlist, production only when `production.allowed` is `true`. [escape hatch: none]
- **[commit-message-gate](../../../hooks/commit-message-gate.sh)** — `PreToolUse:Bash` on `git commit` (also through `command`/`env` wrappers and `git -c`). Denies coverage-expansion / journey-mapping commits that break the conventions, and any commit with AI-attribution metadata: `Co-Authored-By:` naming claude/anthropic, a "Generated with [Claude Code]" marker, or a `claude.ai/code` URL, including `-F` file contents. A bare mention of "claude" passes. [escape hatch: none]
- **[pr-attribution-gate](../../../hooks/pr-attribution-gate.sh)** — `PreToolUse:Bash` on `gh pr create|edit`. Same attribution match as `commit-message-gate`, over the command and `--body-file` / `-F` contents; a PR body never passes through git. [escape hatch: none]
- **[playwright-cli-isolation-guard](../../../hooks/playwright-cli-isolation-guard.sh)** — `PreToolUse:Bash` on `playwright-cli`. Denies a call without the role-prefixed `-s=<slug>` flag, also through `npx`, `pnpm exec`, `sh -c`, `$( )`. A quoted mention passes. Checks slug shape, not who is calling. [escape hatch: none]
- **[protected-artifact-bash-guard](../../../hooks/protected-artifact-bash-guard.sh)** — `PreToolUse:Bash`. Fails closed: a command naming a protected path (registry: `hooks/lib/protected-paths.sh`) is denied unless every command on it is a known read-only command or a known writer with unprotected targets. Interpreters, `eval`, `sh -c`, `xargs`, substitution and wrapper tricks deny as unprovable. Catches the obvious shell vectors; `ledger-integrity-chain` detects the rest. Parser rules: hook header. [escape hatch: none]

### MCP (tracker tools)

- **[adversarial-verification-gate](../../../hooks/adversarial-verification-gate.sh)** — `PreToolUse:mcp__.*` on tracker mutations and `PreToolUse:Bash` on non-draft `gh pr create|ready`. Denies a transition to a completed state (`done|complete|closed|resolved|shipped|released`) or a published PR; warns on a verdict-shaped comment. Passes when `.achilles/adversarial-verification/<ticket>.json` has a `negativeControl` object and is newer than the newest spec. Reads and non-tracker tools pass. Cannot judge that a receipt is honest. [escape hatch: `CIVITAS_DISABLE_ADVERSARIAL_GATE=1`]
- **[evidence-bundle-gate](../../../hooks/evidence-bundle-gate.sh)** — `PreToolUse:mcp__.*` on tracker mutations and `PreToolUse:Bash` on non-draft `gh pr create|ready`. Denies a terminal transition or published PR without an evidence bundle: a directory under `**/evidence/` (or `$ACHILLES_EVIDENCE_DIR`) named for the ticket, with `summary.md` and one of `screenshots/`, `video.webm`, `trace.zip`, `*.har`. Denies on every surface when the HAR or `console.log` holds a live credential. No staleness check. Known limits: hook header. [escape hatch: `CIVITAS_DISABLE_EVIDENCE_GATE=1`]

### Bash + Agent (cross-lifecycle)

- **[deck-inspection-gate](../../../hooks/deck-inspection-gate.sh)** — `PostToolUse:Bash` (record) and `PreToolUse:Agent` (deny). After `export-pdf.js`, renders pages to PNG with `pdftoppm`, writes `.deck-pending-inspection` and tells the agent to Read each image; denies every Agent dispatch until the sentinel is removed after inspection. Without `pdftoppm` it still writes the sentinel. Not activation-gated. [escape hatch: `DECK_INSPECTION_GATE=0`]

## PostToolUse

- **[playwright-artifact-archiver](../../../hooks/playwright-artifact-archiver.sh)** — `PostToolUse:Bash` on Playwright runs; `Stop` / `SubagentStop` backstop. Copies each run's traces, videos, screenshots and `error-context.md` to `<project>/.achilles/runs/<runId>/artifacts/` with a `manifest.json`, because the next run wipes `outputDir`. Keeps the newest `ACHILLES_ARTIFACT_RETAIN` runs (default 5) and skips trace/video blobs over `ACHILLES_ARTIFACT_MAX_MB` (default 512); prunes and skips are named in the manifest. Never denies. [escape hatch: `ACHILLES_ARTIFACT_RETAIN=0`]
- **[subagent-return-schema-guard](../../../hooks/subagent-return-schema-guard.sh)** — `PostToolUse:Agent`, warn by default. Validates the return against `schemas/subagent-returns/<role>.schema.json` and checks the handover envelope's `cycle`. Role map: `hooks/lib/schema-role-map.sh`. Logs each result to `<project>/.achilles/schema-guard-log.jsonl`. [escape hatch: `SCHEMA_RETURN_GUARD=strict` makes it block; the default is non-blocking]
- **[workflow-reviewer-attestation-gate](../../../hooks/workflow-reviewer-attestation-gate.sh)** — `PostToolUse:Agent`, warn only. Warns when a `workflow-reviewer-*` approve cites no file path, or paths that do not exist. The ledger gate's approver check still applies. [escape hatch: none]

## Stop

- **[compliance-sweep-exit-gate](../../../hooks/compliance-sweep-exit-gate.sh)** — `Stop`, `SubagentStop`. Blocks the stop when a `*.spec.*` / `*.test.*` / `*.setup.*` was written and no Stage-4b sweep followed (an **API Compliance Review** heading or a `stage=4b` / `compliance sweep` announcement after the last spec write). Fails open without a transcript; `stop_hook_active` releases after one block. [escape hatch: `CIVITAS_DISABLE_COMPLIANCE_SWEEP_GATE=1`]
- **[run-summary-writer](../../../hooks/run-summary-writer.sh)** — `Stop`. Writes `<project>/.achilles/run-summary.json` from the ledger, adversarial findings, journey map and newest `results.json`; the tests block is null when no result file exists. Never blocks. [escape hatch: n/a]
- **[perf-summary-writer](../../../hooks/perf-summary-writer.sh)** — `Stop`. Writes `<project>/.achilles/perf-summary.json` from the perf ledger, scenarios, k6 summaries and baselines; no-op without `perf-onboarding-status.json`; metrics null when no result exists. Never blocks. [escape hatch: n/a]
- **[selector-development-revert-on-stop](../../../hooks/selector-development-revert-on-stop.sh)** — `Stop`. Warns when a selector-development scope is active and its last passing step is not `visual_diff` or `commit`. [escape hatch: none]

## SubagentStop

- **[playwright-cli-cleanup-on-stop](../../../hooks/playwright-cli-cleanup-on-stop.sh)** — `SubagentStop`. Runs `playwright-cli close-all` to reap orphaned subagent browser sessions, except while `tests/e2e/docs/.phase4-cycle-state.json` exists (parallel cycle agents own their sessions). Never blocks. [escape hatch: none]
