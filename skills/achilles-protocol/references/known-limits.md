# Known limits

One row per limit that ships. `Detector` is the case or lint that pins the behaviour. A change that closes a limit deletes its row. IDs are never reused; a gap means the row was retired or is pending a task in this release.

| ID | Limit | Detector | Owner |
|---|---|---|---|
| KL-03 | `achilles-import-boundary-gate` is a static floor, not a sandbox: it parses the root `playwright*.config.ts` and every file written under `tests/`, and denies what it cannot read. **Denied in the config:** an import outside the allowlist (`@playwright/test`, `@civitas-cerebrum/element-interactions`, `dotenv`, `dotenv/config`, `path`, `url`), any value-producing relative import, other than exactly one export of an object literal / `defineConfig` of them / a const bound to one and referenced nowhere else, a missing top-level `testDir`, a `globalSetup` / `globalTeardown` / `testDir` / `tsconfig` / file reporter outside `tests/`, `projects` other than an array of object literals, `Object.*` / `Reflect` / `Proxy` / `JSON` / `exports` / prototype access, another config extension. **Denied under `tests/`:** a relative specifier outside `tests/` or to a file that is not code or JSON, a Node builtin outside the allowlist in `hooks/lib/import-boundary-scan.js`, a `package.json` / `tsconfig` / `jsconfig` that points outside. **Denied in both:** a specifier that is not one string literal, code that does not parse, `eval` / `Function` / `createRequire` / `Reflect` / `arguments`, `require` other than `require("…")` / `require.resolve("…")`, a loader member (`.require`, `.binding`, `.constructor`, …) on any object. Obfuscated or exotic specifier forms are out of scope (URL and percent-encoded specifiers, dot segments in bare specifiers, `#` and self-reference imports, process-state writes, a case-variant or gitfile-moved project root, the root `package.json`). Not seen: what allowed builtins do at run time, and anything staged by an earlier call. | `cases/86-import-boundary-gate.sh` | methodology |
| KL-12 | Several roles hold write scope on `onboarding-status.json`; who may record which transition is enforced by `onboarding-ledger-write-gate.sh`, not by the mandate; approval-class writes (verdict approvals, terminal status) must come from an approver `agent_type`, and a subagent write with no `agent_type` is denied. | `cases/51-onboarding-ledger-write-gate.sh` | Achilles hooks |
| KL-14 | Without jq, or with a file missing from `hooks/lib/`, a PreToolUse call is denied (exit 2, remedy on stderr) only while the protocol is active; activation is read without jq, and a missing activation lib counts as active. Otherwise each hook keeps its own contract: in an inactive session, and on PostToolUse, Stop and SubagentStop events, 29 hooks exit 1 (a non-blocking error: the call proceeds), 5 allow silently, the 2 summary writers print `{}`, and `playwright-cli-cleanup-on-stop` runs on with failing jq calls. A missing `hooks/lib/hook-io.sh` is not covered: it is the file that does the covering. postinstall bundles jq. | `cases/91-hook-fail-closed.sh` | Achilles hooks (`hooks/lib/hook-io.sh`) |
| KL-15 | The Bash guards judge the plain words of one command line (`hooks/lib/shell-words.sh`). Covered: plain writes, `>`/`>>` redirects, `tee`, `sed -i`, `cp`/`mv`/`rm` onto or into a protected path or an ancestor of one, git `checkout --`/`restore`/`reset --hard`/`clean`/`rm` on protected paths and `checkout -f`/`switch -f` (the work tree when no path is given, judged by the protected state it holds), `find … -delete`, a literal `env -C DIR`, `git -C DIR` or same-line `cd DIR` (a `cd` that does not resolve denies the writes after it), and the `playwright-cli` slug rule (plain, `npx`, `bunx`, `pnpm exec`). Any other program on a line that names protected state or `playwright-cli` denies, and so does a line too long to split. Obfuscated or exotic shell forms are out of scope. Not caught: anything staged by an earlier call (a script, `PATH`, alias, function or `cd`); `ledger-integrity-chain` detects an out-of-band ledger change. | `cases/92-protected-bash-fail-closed.sh`, `cases/57-protected-artifact-bash-guard.sh`, `cases/02-cli-isolation-guard.sh` | Achilles hooks |
| KL-17 | `spend-gate` and `commit-gate` split the command quote-aware and classify one level of `sh -c` / `eval`. Aliases, functions, scripts that call the runner, interpreter one-liners (`node -e`) and encoded paths are not seen. The wrapper excludes the spend list by default. | `hooks/tests/cases/factory/spend-gate.deny-eval-checkout-order.json`, `commit-gate.deny-sh-dash-c-commit.json` | Achilles hooks |
| KL-18 | Factory write gates read the written text, not the program: comment masking is line based, and a title or selector built at run time is not seen. | `hooks/tests/cases/factory/common.deny-code-after-block-comments.json` | project verify step |
| KL-19 | Factory gates normalise paths lexically (`.`, `..`, `//`); a symlinked directory is judged by its link path. | `hooks/tests/cases/factory/common.deny-dotdot-frozen-path.json` | Achilles hooks |
| KL-20 | `state-gate` covers the primary ways an agent writes the process-state directory: a redirect, `tee`, `cp`/`mv`/`rm`/`sed -i`, `git checkout`/`restore` or any non-reader naming the directory, the stamp or the change marker, and `cd` into the directory followed by a write ([factory-gates.md](factory-gates.md#process.state)). Obfuscated or exotic forms are out of scope and pass: a glob, brace or quote splice in the name (`.fact*`, `.fac""tory`), a `$X` prefix, a name built at run time (`D=.fac; rm ${D}tory/x`), a command string run by another program (`find -exec sh -c`, `rsync -e`, `LESSOPEN`), shell-option and `HOME`/`CDPATH`/`OLDPWD` tricks, `rsync` copies, state staged by an earlier call (a symlink, alias, function or variable), and text fed to an interpreter (`echo … \| sh`). A whole-tree destroyer that names neither the directory nor its files (`rm -rf .`, `find . -delete`, `git clean -fdx`, `git stash -u`) deletes the stamp, which fails closed at commit-gate (a) until a fresh verify, and the change marker, which turns the next commit after that verify into a maintenance commit that skips the evidence-trail check (b); the change reviewer owns catching that. The commit gate's tree-hash check is no backstop: `hashCommand` is a repo script any agent can run, so a hand-written stamp can carry the current tree's hash, and state-gate is the only barrier against one. A read-only command outside the reader list is denied (`sed -n`, `awk`, `less`, `bash -c 'cat …'`): use `cat`, `head`, `grep`, `jq` or a listed `git` read. | `hooks/tests/cases/factory/state-gate.deny-cd-then-rm.json`, `state-gate.deny-redirect.json` | Achilles hooks |
| KL-21 | A user-level skill wins over a project skill of the same name. With a global install beside local ones, every project runs the global copy of the skills; a 0.1.8 local install left unrecorded user-level copies, which postinstall names but does not delete. | `install-simulation.sh` §scope | Achilles install |
| KL-22 | `@civitas-cerebrum/sql-client`, a dependency of element-interactions, runs its own postinstall: it copies its `sql-client` skill to `~/.claude/skills/` on every install and, on `npm i -g`, to a `.claude/` under npm's `lib/`. Set `SQL_CLIENT_SKIP_SKILLS=1` before installing to stop it. | `install-simulation.sh` §npm-global (sets the switch) | sql-client upstream |

## Runtime requirements

| Requirement | Why | When missing |
|---|---|---|
| jq | every hook parses JSON with it | postinstall bundles one; hooks fall back to PATH; with neither, PreToolUse gates deny while the protocol is active (KL-14) |
| Node ≥ 20 | validator bundle, parser bundle, postinstall, CLIs | schema-validating hooks warn and allow; `achilles-import-boundary-gate` denies |
