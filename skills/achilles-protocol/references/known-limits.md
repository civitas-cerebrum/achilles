# Known limits

One row per limit that ships. `Detector` is the case or lint that pins the behaviour. A change that closes a limit deletes its row. IDs are never reused; a gap means the row was retired or is pending a task in this release.

| ID | Limit | Detector | Owner |
|---|---|---|---|
| KL-01 | The kernel does not inspect the text of a dispatch brief; a dispatcher can pass anything it can read to a child. | kernel design (vendored) | kernel-mandate upstream |
| KL-02 | Roles that author and run code are contained by a static import/capability screen, not a sandbox. | upstream kernel-mandate case 07-write-then-execute | kernel-mandate upstream |
| KL-03 | `achilles-import-boundary-gate` is a static floor, not a sandbox: it parses the root `playwright*.config.ts`, the root `package.json` and every file written under `tests/`, and denies what it cannot read. Test code runs with full Node privileges; this screen is a static floor against accidental or careless reach into `src/`, not a sandbox. **Denied in the config:** an import outside the allowlist (`@playwright/test`, `@civitas-cerebrum/element-interactions`, `dotenv`, `dotenv/config`, `path`, `url`, bare or `node:`), any value-producing relative import, more than one export, an export that is not an object literal / `defineConfig` of them / a const bound to one and referenced nowhere else, a missing top-level `testDir`, any `globalSetup` / `globalTeardown` / `testDir` / `tsconfig` / file reporter outside `tests/`, `projects` other than an array of object literals, `Object.*` / `Reflect` / `Proxy` / `JSON` / `exports` / prototype access, another config extension. **Denied under `tests/`:** a relative specifier outside `tests/`, `#` and self-reference imports, any Node builtin outside the allowlist (`fs`, `fs/promises`, `path`, `url`, `os`, `crypto`, `util`, `buffer`, `stream`, `stream/promises`, `events`, `assert`, `assert/strict`, `timers`, `timers/promises`, `zlib`, `http`, `https`, `querystring`, `string_decoder`, `readline`, `perf_hooks`, plus `path/posix`, `path/win32`, `util/types`; bare or `node:`). Other bare packages are the kernel's codeImports. **Denied in both:** a URL-scheme specifier other than `node:` (`file:`, `data:`, `http:`; `https:` passes only under `tests/perf/**`, where k6 scenarios import jslib — Node itself never loads `https:`); a bare specifier with a `.` or `..` segment (`zz/../../src/app.js`, `https://../../src/app.js`, `lodash/../../src/app.js` resolve from `node_modules` and climb into the project) and any specifier containing `%` (the ESM resolver decodes `%2e%2e` to `..`); `eval`, `Function` (as a value), `createRequire`, `Reflect`, `arguments`; `process` / `module` / `globalThis` / `global` as values or through computed keys; any write to `process` state — assignment (including destructuring patterns, `for…of`/`for…in` targets), `+=`, `delete` — on `process.env.*`, `process.execPath` or any other `process`-rooted member, `process.env` passed on (`Object.assign(process.env, …)`, bound to a name), any reference to `process.execArgv` or `process.loadEnvFile`; `.require` / `._load` / `._compile` / `.constructor` / `.mainModule` / `.binding` / `._linkedBinding` / `.getBuiltinModule` / `.dlopen` / `.execve` / `.arguments` / `.caller` on any object, those names as destructuring keys or bare strings, and a computed key assembled from strings. **Not seen:** the runtime behaviour of allowed builtins (`fs.writeFileSync` or `fs.symlinkSync` creating a file the same or a later run loads, `http` fetching code), runtime writes under `tests/` by test code or by `npx playwright test > tests/e2e/x` redirects, config `webServer.command` (arbitrary shell), `use.launchOptions.executablePath`, the root tsconfig's `paths` (read by Playwright when the config names no `tsconfig`), `NODE_OPTIONS` in any env file dotenv reads (`.env`, or one under `tests/`, which passes as prose), a loader name reached through data the screen does not trace (a parameter, array element, property read or `.join` result used as a computed key), `.load(…)` on any object (every static route to a `Module` instance is denied instead), prototype pollution from code under `tests/` (runs after the config is resolved). **Known false positives:** `err.constructor.name` (use `err.name` or `instanceof`); `.d.ts` files with `export = require("../…")` or `import x = require("../…")` (type-only, but screened as code); `const { env } = process` and `globalThis.process.env.X` (write `process.env.X`); `arguments` inside an ordinary `function`. | `cases/86-import-boundary-gate.sh` §"import-boundary-gate: config indirection", §"the environment, the module wrapper and URL specifiers", §"Node builtins under tests/ come from an allowlist", §"loader aliases under tests/", §"the screen fails closed" | methodology |
| KL-04 | The scaffolder is the only role that reads or writes `.env`. Its return reaches the orchestrator unvalidated (no schema mapping for `scaffolder-*`), and "never echo values" is methodology that nothing enforces. | `cases/85-qa-mandate-scopes.sh` §secrets-sweep-phase7 | methodology |
| KL-05 | The perf pipeline is not modelled in the QA mandate: under an active kernel `k6 run` and perf worker dispatches are refused. | KL-14 | Without jq, or with a file missing from `hooks/lib/`, a PreToolUse call is denied (exit 2, remedy on stderr) only while the protocol is active; activation is read without jq, and a missing activation lib counts as active. Otherwise each hook keeps its own contract: in an inactive session, and on PostToolUse, Stop and SubagentStop events, 29 hooks exit 1 (a non-blocking error: the call proceeds), 5 allow silently, the 2 summary writers print `{}`, and `playwright-cli-cleanup-on-stop` runs on with failing jq calls. A missing `hooks/lib/hook-io.sh` is not covered: it is the file that does the covering. postinstall bundles jq. | `cases/91-hook-fail-closed.sh` | Achilles hooks (`hooks/lib/hook-io.sh`) |
| KL-15 | The Bash guards judge one command line's own words (`hooks/lib/shell-words.sh`), inverting to unrecognised = unsafe within it: a static floor. The commands inside a brace group, a function body, a `$( )` and a script a shell, `eval`, `env -S` or `npx -c` runs are judged where they are written. On the line itself `protected-artifact-bash-guard` treats every unrecognised option, program, sed command, wrapper option and git option as unsafe. `playwright-cli-isolation-guard` denies a command whose words, assignments, heredoc bodies or directory name `playwright-cli` in any letter case, and every command word that expands (`$x`, a glob, a backtick), unless the command is `playwright-cli` behind wrappers and options the splitter knows, a shell or `eval` whose only mention is its script, or a reader from the closed list in the guard header. **Not caught:** a target, program or config staged by an earlier call (a renamed binary, a `PATH`/alias/function/`git config`/`BASH_ENV` set in a previous tool call, a script file written earlier); a path or command built at run time (a variable assembled from parts such as `p=playwright; ${p}-cli`, `cd`, a symlink); text piped or fed into an interpreter or `xargs` at run time (`echo … \| sh`, `echo playwright-cli open \| xargs`, `xargs eval <<< …`, `source <(echo …)`, `base64 -d \| sh`, `source x`); a `BASH_ENV`/`ENV` file staged by an earlier call, even when the variable is set inline; a `{` program on `PATH` (judged as a brace group); a Unicode look-alike of a protected name (a different file). `ledger-integrity-chain` detects the resulting out-of-band ledger change. | `cases/92-protected-bash-fail-closed.sh`, `cases/02-cli-isolation-guard.sh` | Achilles hooks |
| KL-16 | `verify.md` `Status: complete` is path-gated (only the verifier writes it), not content-gated: a verifier can record `complete` beside a FAIL verdict. | `cases/72-change-loop-roles.sh` | methodology |
| KL-17 | `spend-gate` and `commit-gate` split the command quote-aware and classify one level of `sh -c` / `eval`. Aliases, functions, scripts that call the runner, interpreter one-liners (`node -e`) and encoded paths are not seen. The wrapper excludes the spend list by default and the commit gate recomputes the tree hash, so a forged stamp passes only with the current tree's hash. | `hooks/tests/cases/factory/spend-gate.deny-eval-checkout-order.json`, `commit-gate.deny-sh-dash-c-commit.json` | Achilles hooks |
| KL-18 | Factory write gates read the written text, not the program: comment masking is line based, and a title or selector built at run time is not seen. | `hooks/tests/cases/factory/common.deny-code-after-block-comments.json` | project verify step |
| KL-19 | Factory gates normalise paths lexically (`.`, `..`, `//`); a symlinked directory is judged by its link path. | `hooks/tests/cases/factory/common.deny-dotdot-frozen-path.json` | Achilles hooks |
